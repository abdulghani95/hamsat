# همسة

تطبيق مراسلة بنفسجي بواجهة عصرية يرسل **عبر الإنترنت** مثل واتساب، ويعمل **بلا رقم هاتف ولا بريد**: هويتك اسم مستخدم وكلمة مرور، ويمكنك ربط رقم هاتفك اختياريًا ليجدك أصدقاؤك به.

واجهة HTML + CSS + JavaScript بلا مكتبات، تتصل بخادم Firebase المجاني (حسابات وقاعدة بيانات لحظية) عبر REST. تثبّت كتطبيق (PWA) أو كملف APK. **لا توجد أسماء أو محادثات افتراضية**: تبدأ فارغًا وتضيف أصدقاءك بأسماء مستخدميهم. اتبع **SETUP.md** لربطه بالخادم مرة واحدة.

## المميزات

| الميزة | ما تفعله |
| --- | --- |
| مراسلة حقيقية | حسابات باسم مستخدم وكلمة مرور، وبحث عن الأصدقاء باسم المستخدم أو برقم الهاتف (اختياري، غير موثّق) |
| صور وصوت وحالات | إرسال صور ورسائل صوتية، وحالات تختفي بعد 24 ساعة مع قائمة المشاهدين |
| رسائل تتلاشى | تختار 10 ثوانٍ أو 30 ثانية أو دقيقة، فتختفي الرسالة من المحادثة |
| كبسولة زمنية | رسالة تظهر مقفلة بعدّاد تنازلي وتُفتح في الوقت الذي تحدده |
| رسائل سرية | تظهر مموّهة، وتُقرأ مرة واحدة لمدة 6 ثوانٍ ثم تُحرق ويُمسح نصها |
| وضع الشبح | يخفي أثر القراءة والكتابة، مع شريط تنبيه في المحادثة |
| هالة المزاج | حلقة ملونة متحركة حول الصورة تعبّر عن المزاج (هادئ، متحمس، مبدع، عاطفي، مركّز) |
| إخفاء المعاينة | تمويه آخر رسالة في قائمة المحادثات |
| وضع فاتح وداكن | يتبع إعداد الجهاز تلقائيًا |

## التشغيل محليًا

يتطلب Node.js 20 أو أحدث.

```bash
npm start
```

ثم افتح <http://localhost:8080>.

## الاختبارات

```bash
npm install                      # مرة واحدة (يثبّت Playwright فقط)
npx playwright install chromium  # مرة واحدة
npm test                         # اختبارات المنطق والملفات (بلا اعتماديات)
npm run test:e2e                 # اختبارات المتصفح الكاملة
npm run test:all                 # الاثنان معًا
```

لتشغيل اختبارات المتصفح بمتصفح Chrome المثبّت عندك بدل متصفح Playwright:

```bash
CHROME_PATH="/path/to/chrome" npm run test:e2e
```

## النشر على GitHub

```bash
cd hamsa
git init -b main
git add .
git commit -m "همسة: النسخة الأولى"
git remote add origin https://github.com/<اسمك>/hamsa.git
git push -u origin main
```

بعد الرفع:

1. افتح المستودع على GitHub ثم **Settings → Pages**.
2. في **Build and deployment** اختر **Source: GitHub Actions**.
3. يعمل الـ workflow المسمى `Deploy to GitHub Pages` تلقائيًا عند كل دفع إلى `main`، ويظهر الرابط في تبويب **Actions**، وغالبًا بالشكل `https://<اسمك>.github.io/hamsa/`.

الـ workflow المسمى `CI` يشغّل كل الاختبارات عند كل دفع وكل Pull Request.

## تثبيته كتطبيق

افتح الرابط من Chrome على أندرويد ثم **إضافة إلى الشاشة الرئيسية**، أو من Safari على آيفون ثم **مشاركة → إضافة إلى الشاشة الرئيسية**. يعمل بعد ذلك دون اتصال.

## المراسلة عبر الإنترنت

التطبيق يرسل عبر الإنترنت فعلًا باستخدام Firebase (حساب Google مجاني يكفي للتجربة):

- تسجيل الدخول باسم مستخدم وكلمة مرور (الاسم يتحول داخليًا إلى `username@hamsa.app`، ولا يُطلب بريد حقيقي).
- رقم الهاتف اختياري، يُخزَّن مجزّأً (SHA-256) فقط ليتمكن الأصدقاء من البحث به، وهو غير موثّق برسالة نصية.
- لا توجد أسماء أو جهات اتصال افتراضية. البحث يتم بالاسم الكامل أو بالرقم مع رمز الدولة.
- الإعداد خطوة واحدة: ألصق مفتاحين في `js/config.js`. التفاصيل في [SETUP.md](SETUP.md).
- قواعد الأمان في `database.rules.json` (كل شخص يكتب في ملفه فقط، والمحادثة لا يقرؤها إلا طرفاها).

### حدود صريحة

- الرسائل **غير مشفّرة طرفًا لطرف**: مالك مشروع Firebase يستطيع قراءتها.
- لا إشعارات والتطبيق مغلق (تحتاج خادمًا إضافيًا وFCM).
- كلمة المرور لا يمكن استعادتها (لا بريد حقيقي).
- الصور والصوت تُخزَّن داخل قاعدة البيانات، لذا الاستخدام الكثير يستهلك الحصة المجانية.
- اختباراتنا تعمل على خادم تجريبي يحاكي Firebase، ولم تُجرَّب على Firebase الحقيقي من بيئة التطوير.
